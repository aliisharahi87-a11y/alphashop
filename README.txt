ALPHA SHOP WEBSITE PRO
=======================

ساختار صفحه:
1) سرورهای مولتی‌لوکیشن آلفا شاپ
2) Gemini Pro
3) Telegram Premium
4) ChatGPT Plus (ناموجود)

امکانات:
- صفحه اصلی خلوت و حرفه‌ای با ۴ کارت محصول
- کلیک روی هر کارت => پنجره اختصاصی همان محصول
- پنجره مولتی‌لوکیشن: پلن‌های ۵/۱۰/۲۰/۴۰ گیگ و لینک به بات
- Gemini Pro: یک ماهه، قیمت ۳۵۰,۰۰۰ تومان، گارانتی کامل، فعال‌سازی روی اکانت شخصی
- Telegram Premium: یک ماهه ۱,۸۰۰,۰۰۰ و دوماهه ۳,۱۰۰,۰۰۰ تومان
- ChatGPT Plus: وضعیت ناموجود
- نمایش قیمت قبلی با افزایش ۲۷٪، خط‌خورده + برچسب ۲۷٪ تخفیف
- دکمه‌های خرید Gemini/Telegram پیام آماده برای @AlphaShopSupport باز می‌کنند
- پیام خرید شامل محصول، قیمت و درخواست مراحل خرید است
- توضیحات، شرایط فعال‌سازی و متن نقد/بررسی داخل پنجره هر محصول
- لینک پشتیبانی و بات
- طراحی Dark Neon
- ریسپانسیو برای موبایل
- پنجره‌ها با کلیک بیرون یا ESC بسته می‌شوند
- دکمه تغییر حالت آماده است (برای نسخه بعدی می‌توان Light Mode کامل اضافه کرد)

نکته فنی:
لینک‌های مولتی‌لوکیشن فعلاً Deep Link به بات هستند. برای خرید کاملاً خودکار با کیف پول،
باید در bot.py پارامتر start مثل buy_5GB را دریافت کنیم، موجودی را بررسی کنیم،
سرویس را از پنل بسازیم و لینک کانفیگ را مستقیماً برای کاربر ارسال کنیم.
